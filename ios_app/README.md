# 📱 مشروع تطبيق الآيفون (iPhone Native Media Optimizer)
### تطبيق أصلي بلغة Swift و SwiftUI لضغط مكتبة وسائط الآيفون محلياً 100% بدون وسيط

---

## 🌟 المعمارية المعتمدة

تم بناء هذا الكود البرمجي بالاعتماد على أطر عمل أبل الرسمية لتحقيق التوافق والأمان الكامل:

1. **`PhotoKitManager.swift`:**
   * إدارة أذونات مكتبة صور أبل (`PHPhotoLibrary`).
   * فحص وتصنيف الصور العادية، الفيديوهات، والصور الحية (Live Photos).
   * الاستبدال الآمن والحذف الرسمي عبر نافذة أبل الأمنية ونقل النسخ الثقيلة لـ "المحذوفة مؤخراً".

2. **`ImageCompressor.swift`:**
   * ضغط الصور بجودة عالية بصيغة HEIC و JPEG عبر `ImageIO`.
   * **حفظ الميتاداتا 100%:** نسخ واستنساخ كافة قواميس الـ EXIF، الـ TIFF، وبيانات الـ GPS بدون فقدان.

3. **`VideoCompressor.swift`:**
   * ضغط الفيديو باستخدام المسرّع العتادي لشريحة المعالج (Apple Silicon VideoToolbox).
   * التشفير بمعمارية HEVC H.265 القياسية لآبل مع الحفاظ على مسارات الصوت الأصلية وبيانات QuickTime.

4. **`LivePhotoCompressor.swift`:**
   * الحفاظ على أزواج الصور الحية الحقيقية وضمان عدم فك ارتباطها.
   * فحص شرط المدة ($\le 3.5$ ثوانٍ) لمنع خلط الفيديوهات الطويلة كصور حية.
   * الحفظ المباشر عبر `PHAssetCreationRequest` كصورة حية رسمية تتحرك باللمس.

5. **`ThermalGuard.swift`:**
   * مراقبة درجة حرارة معالج الهاتف لحظياً (`ProcessInfo.ThermalState`).
   * تهدئة المعالجة تلقائياً عند ارتفاع الحرارة لحماية البطارية وتجنب السخونة.

6. **`ContentView.swift`:**
   * واجهة مستخدم حديثة ومبنية بالكامل بـ `SwiftUI` تدعم اللغة العربية.
   * لوحة تحكم ذكية تعرض إحصائيات الاستديو، المساحة المتوقع توفيرها، وشريط التقدم.

---

## 🚀 طريقة الفتح والتشغيل في Xcode:

1. افتح بيئة **Xcode** على جهاز Mac (أو عبر جهاز ظاهري/سحابي).
2. اختر **Create New Project** -> **App** -> واجعل الواجهة **SwiftUI** ولغة البرمجة **Swift**.
3. أضف الملفات الموجودة في مجلد `Sources/` إلى مشروعك.
4. في إعدادات المشروع (`Info.plist`) أضف إذن مكتبة الصور:
   * `Privacy - Photo Library Usage Description`
5. شغّل المشروع مباشرة على جهاز الآيفون الخاص بك لتجربة الضغط محلياً!
