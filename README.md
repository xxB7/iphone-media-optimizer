# 📱 أداة تخفيف استديو الآيفون (iPhone DCIM Media Optimizer)
### نظام إنتاجي متكامل (Production-Grade) لضغط مكتبة وسائط الآيفون مع الحفاظ بنسبة 100% على الميتاداتا والترتيب الزمني والجغرافي

---

## 🌟 أبرز مميزات النظام

1. **حفاظ مطلق ودقيق 100% على الميتاداتا (Zero Data Loss):**
   - استنساخ كافة وسوم EXIF، التاريخ، والوقت، ونموذج الكاميرا، وإحداثيات الـ GPS.
   - ضبط دقيق للمنطقة الزمنية مع معالجة توقيت QuickTime UTC لمنع أي إزاحة في تواريخ الفيديوهات عند عرضها داخل تطبيق Apple Photos.
   - مزامنة تواريخ نظام ملفات ويندوز (Windows File Creation & Modification Times) عبر استدعاءات Win32 API المباشرة.

2. **دعم الصور الحية (Live Photos Pairing):**
   - التعرف التلقائي على أزواج الصور الحية (`IMG_xxxx.HEIC` + `IMG_xxxx.MOV`).
   - استنساخ وحفظ معرّف الربط التشفيري `QuickTime:ContentIdentifier` في مقاطع الفيديو لضمان استمرار تفاعل وعمل الصور الحية عند إعادتها للآيفون.

3. **تسريع فائق عبر كرت الشاشة (NVIDIA NVENC HEVC):**
   - تشفير عتادي للفيديوهات باستخدام كرت الشاشة (NVIDIA GeForce RTX 3060 Ti) بمعمارية H.265/HEVC.
   - كشف تلقائي لفيديوهات الـ 10-bit و HDR (Dolby Vision / HLG) لضمان عدم شحوب الألوان أو بهتانها (`-pix_fmt p010le -profile:v main10`).
   - إضافة وسم التوافق الإلزامي لبيئة آبل (`-tag:v hvc1`).
   - تمرير الصوت الأصلي دون إعادة تشفير (`-c:a copy`) للحفاظ على جودة 100% والصوت المكاني (Spatial Audio) مع سرعة تشفير فائقة.

4. **ضغط متقدم للصور (HEIC / JPG / PNG):**
   - ضغط صور HEIC عالية الكفاءة عبر `pillow-heif` مع خفض الحجم بنسبة 50-75% دون أي فرق ملحوظ للعين المجردة.
   - دعم كامل لصور JPEG مع تفعيل MozJPEG/Optimized DCT.
   - نقل ملفات التعديل المساندة (`.AAE`) تلقائياً لضمان عدم ضياع أي فلتر أو تعديل سابق قمت به داخل الآيفون.

5. **نظام الاستئناف الذكي وقاعدة بيانات الحالات (SQLite Resume Engine):**
   - متابعة لحظية لحالة كل ملف عبر قاعدة بيانات SQLite محلية (`optimizer_state.db`).
   - في حال إيقاف البرنامج أو انقطاع التيار، يمكنك إعادة التشغيل فوراً ليستأنف من حيث توقف دون إعادة ضغط الملفات المنجزة.

6. **أمان البيانات والكتابة الذرية (Atomic Writes & Safety First):**
   - مجلد الإدخال للقراءة فقط (Read-Only).
   - الكتابة في ملفات مؤقتة (`.tmp`)، والتحقق من سلامة البنية بـ `ffprobe` أو `Image.verify()` قبل اعتماد النتيجة.
   - ميزة الإبقاء على الأصل: إذا كان الملف بعد الضغط أكبر أو مساوياً للأصل (نادر في بعض الصور)، يحتفظ النظام بالملف الأصلي فوراً.

7. **معالجة تامة لمسارات ويندوز وأسماء المجلدات العربية:**
   - تم تصميم المحرك ليتعامل مع المسارات الطويلة، واللغة العربية، والرموز دون أي خطأ في ExifTool عبر تقنية الـ UTF-8 Argfiles المبتكرة.

## ⚙️ متطلبات العتاد والبرمجيات

- **نظام التشغيل:** Windows 10 / 11 (64-bit)
- **المعالج:** Intel Core i7 أو ما يعادله
- **الذاكرة العشوائية (RAM):** 16GB إلى 32GB
- **كرت الشاشة:** NVIDIA RTX 3060 Ti أو أي كرت NVIDIA يدعم NVENC
- **البرمجيات المثبتة:**
  - Python 3.10+
  - FFmpeg (مفعل به `hevc_nvenc`)
  - ExifTool (مثبت ومكتشف تلقائياً)

## 🚀 طريقة التثبيت والتشغيل

### 1. تثبيت المكتبات (مرة واحدة فقط):
```bash
pip install -r requirements.txt
```

### 2. التشغيل التفاعلي السهل:
يمكنك ببساطة تشغيل البرنامج، وسيطلب منك إدخال مسار مجلد الآيفون ومسار مجلد الحفظ:
```bash
python main.py
```

### 3. التشغيل عبر سطر الأوامر (Command Line):
```bash
python main.py -i "D:\iPhone_DCIM" -o "D:\Compressed_DCIM"
```

### 4. خيارات إضافية متقدمة:
- **تجربة وهمية دون تعديل (Dry Run):**
  ```bash
  python main.py -i "D:\iPhone_DCIM" -o "D:\Compressed_DCIM" --dry-run
  ```
- **تعديل معامل جودة الفيديو (CQ):** (الافتراضي 28، كلما زاد الرقم صغر الحجم)
  ```bash
  python main.py -i "D:\iPhone_DCIM" -o "D:\Compressed_DCIM" --cq 30
  ```
- **تعديل جودة الصور:** (الافتراضي 72)
  ```bash
  python main.py -i "D:\iPhone_DCIM" -o "D:\Compressed_DCIM" --photo-quality 75
  ```
- **إعادة فك وضغط المكتبة من الصفر (تجاهل قاعدة بيانات الاستئناف):**
  ```bash
  python main.py -i "D:\iPhone_DCIM" -o "D:\Compressed_DCIM" --reset-db
  ```

## 📊 ملف الإعدادات (`config.yaml`)

يمكنك تخصيص كل شيء في الأداة من خلال تعديل ملف `config.yaml`:
- قيم الـ Preset والـ CQ للفيديو.
- جودة صور HEIC و JPG.
- أقصى عدد لخيوط كرت الشاشة (GPU Video Workers) وخيوط المعالج (CPU Photo Workers).
- خيارات التحقق والسلامة.
