# 📱 أداة تخفيف استديو الآيفون (iPhone DCIM Media Optimizer)
### نظام إنتاجي متكامل (Production-Grade) لضغط وهندسة مكتبة وسائط الآيفون مع الحفاظ بنسبة 100% على الميتاداتا، وترتيب الألبومات، والصور الحية

---

## 🌟 نظرة عامة
نظام متكامل ومفتوح المصدر مصمم خصيصاً لهندسة، وضغط، وتصحيح، وإعادة استيراد مكتبات وسائط أجهزة iPhone الضخمة (التي تتجاوز عشرات الجيجابايت وعشرات الآلاف من الملفات) بكفاءة عتادية فائقة مع الحفاظ المطلق بنسبة 100% على الميتاداتا، والترتيب الزمني، والتوزيع الجغرافي، والصور الحية (Live Photos)، والألبومات المخصصة.

---

## 🛠️ أبرز مميزات النظام

1. **حفاظ مطلق ودقيق 100% على الميتاداتا (Zero Data Loss):**
   - استنساخ كافة وسوم EXIF، التاريخ، والوقت، ونموذج الكاميرا، وإحداثيات الـ GPS.
   - ضبط دقيق للمنطقة الزمنية ومعالجة توقيت QuickTime UTC لمنع أي إزاحة في تواريخ الفيديوهات عند عرضها داخل تطبيق Apple Photos.
   - مزامنة تواريخ نظام ملفات ويندوز (Windows File Creation & Modification Times) عبر استدعاءات Win32 API المباشرة.
   - حقن تلقائي للطوابع الزمنية التاريخية في الصور والفيديوهات التي تفتقر لبيانات الكاميرا الأصلية (مثل وسائط الواتساب وشبكات التواصل).

2. **الدعم الذكي للصور الحية (Smart Live Photos Pairing):**
   - التعرف التلقائي الذكي على أزواج الصور الحية (`IMG_xxxx.HEIC/.JPG` + `IMG_xxxx.MOV`).
   - التحقق من شروط أبل للصور الحية (مدة الفيديو $\le$ 3.5 ثانية ومطابقة `ContentIdentifier`).
   - استبعاد الفيديوهات العادية الطويلة التي تشترك في نفس الاسم ومنع تصنيفها الخاطئ كصور حية.

3. **معالجة وتطبيع الصيغ غير المتوافقة (Format Standardization):**
   - تحويل تلقائي لصور الـ PNG الضخمة (لقطات الشاشة) إلى JPG قياسي عالي الجودة مع توفير أكثر من 85% من حجمها وحقن وسوم `DateTimeOriginal` بداخلها.
   - تحويل صيغ الويب والفوتوشوب (WebP, PSD, BMP, TIFF) إلى صيغ أبل القياسية.
   - عزل تلقائي لأي ملفات تالفة أو فارغة بحجم (0 بايت) لمنع تعليق النقل.

4. **حل تعارضات الأسماء التلقائي (Stem Collision Elimination):**
   - خوارزمية ذكية تفحص أسماء الملفات وتفك تشابك أي ملفات غير مرتبطة تحمل نفس الاسم (مثل `IMG_0001.JPG` لصورة و `IMG_0001.MOV` لفيديو مستقل).
   - ضمان نسبة قبول 100% وتفادي خطأ الرفض الشهير في برامج النقل (`Photos failed to import`).

5. **تسريع فائق عبر كرت الشاشة (NVIDIA NVENC HEVC):**
   - تشفير عتادي للفيديوهات باستخدام كرت الشاشة (NVIDIA NVENC) بمعمارية H.265/HEVC.
   - كشف تلقائي لفيديوهات الـ 10-bit و HDR (Dolby Vision / HLG) لضمان عدم شحوب الألوان (`-pix_fmt p010le -profile:v main10`).
   - إضافة وسم التوافق الإلزامي لبيئة آبل (`-tag:v hvc1`).
   - تمرير الصوت الأصلي دون إعادة تشفير (`-c:a copy`) للحفاظ على جودة 100% والصوت المكاني.

6. **إدارة الألبومات والاستيراد التلقائي (Album Manager):**
   - فرز وحفظ ألبومات التطبيقات (Snapchat, WhatsApp, Instagram) في مجلدات مخصصة.
   - تجميع الصور العامة في مجلد رئيسي موحد مع صفر تكرار وصفر تعارض في الأسماء.
   - توليد دليل استيراد تنفيذي تفاعلي بصيغة Markdown يشرح خطوات النقل والفرز بالآيفون.

## 🧠 سجل الدروس الميدانية والمشاكل الـ 10 الكبرى (Engineering Lessons)

تم اختبار هذا النظام على مكتبة حقيقية ضخمة (~73.5 جيجابايت، 31,089 ملف، iPhone 14 Pro Max)، وتوثيق وحل المشاكل التالية برمجياً:

| # | التحدي البرمجي / الميداني | السبب الجذري | الحل المدمج في النظام |
| :-: | :--- | :--- | :--- |
| **1** | **ملفات الشبح في الآيفون (Ghost Files)** | محاولة رفع الملفات عبر AFC إلى `DCIM/` تجاوزت قاعدة بيانات `Photos.sqlite` وملأت 205 جيجابايت كملفات وهمية. | حظر الرفع المباشر لـ DCIM واعتماد واجهات PhotoKit عبر 3uTools مع سكريبت تنظيف فوري لملفات الشبح. |
| **2** | **برامج النقل المدفوعة ومشاكل SMB** | مطالبة برامج مثل iMazing باشتراكات، وتعليق SMB في ويندوز 11. | بناء مسار مجاني 100% عبر كيبل الـ USB وبروتوكول usbmuxd عالي السرعة. |
| **3** | **تضخم صور PNG وفقدان التواريخ** | لقطات الشاشة لا تحتوي على وسوم EXIF وتستهلك أحجاماً هائلة. | محرك تحويل تلقائي من PNG إلى JPG عالي الجودة مع حقن طابع `DateTimeOriginal` الزمني. |
| **4** | **صيغ WebP و PSD غير المتوافقة** | رفض تطبيق الصور في iOS للملفات غير القياسية. | تطبيع فوري لجميع صيغ الويب والتصميم إلى JPEG قياسي متوافق مع آبل. |
| **5** | **تكرار وتشتت الصور الحية** | وجود نسخ مكررة من الصور الحية مفصولة بين الألبومات والمكتبة العامة. | عزل أزواج الصور الحية الحقيقية وتطهير المجلد العام من أي نسخ مكررة. |
| **6** | **تعارض وتشابه الأسماء (Stem Collisions)** | تشابه أرقام `IMG_xxxx` بين صورة قديمة وفيديو جديد يسبب رفض 3uTools للملفات. | وحدة `CollisionResolver` المدمجة التي تلحق لاحقات فريدة (`_g1`, `_v1`) تضمن 0 تعارض. |
| **7** | **تواريخ الواتساب المفقودة (ظهور الصور بتاريخ اليوم)** | الصور المرسلة في المحادثات تفتقر لبيانات EXIF، فيضعها iOS بتاريخ اليوم ولحظة الاستيراد. | فحص وحقن تاريخ التعديل الأصلي في وسوم EXIF لكل ملف، مما يعيدها لسنواتها الصحيحة (2018-2025). |
| **8** | **فرز الألبومات المخصصة في iOS** | نظام iOS يضع الألبومات المخصصة افتراضياً على "ترتيب مخصص" أو "تاريخ الإضافة". | توثيق وتوضيح إعداد الفرز بالآيفون: النقاط الثلاث `•••` -> فرز -> من الأقدم إلى الأحدث. |
| **9** | **الصور الحية المزيفة (رفض 130 Live Photo)** | وجود فيديوهات عادية طويلة مدتها 25 ثانية بنفس اسم الصورة يرفضها 3uTools كـ Live Photo. | فحص مدة الفيديو ومطابقة `ContentIdentifier`؛ فك ارتباط الفيديوهات الطويلة واستيرادها كفيديوهات عادية. |
| **10** | **الملفات الفارغة والتالفة (0-Byte Files)** | وجود ملفات تالفة فارغة (مثل `IMG_2733.PNG`) يعلق عمليات الفحص والاستيراد. | فلتر حجر صحي تلقائي يعزل أي ملف تالف بحجم صفر بايت إلى مجلد `_corrupt_quarantine`. |

## 🚀 طريقة الاستخدام

### 1. التثبيت السريع:
```bash
pip install -r requirements.txt
```

### 2. التشغيل الكامل (فحص + ضغط + حزم + تصحيح ميتاداتا):
```bash
python main.py
```
أو سطر الأوامر المباشر:
```bash
python main.py -i "D:\iPhone_DCIM" -o "E:\استديو مخفف"
```

### 3. خيار الحزم والتحقق فقط (Package & Verify Only):
إذا كانت الملفات مضغوطة مسبقاً وتريد فقط فك تعارضات الأسماء وحقن التواريخ الناقصة وتوليد دليل الاستيراد:
```bash
python main.py -o "E:\استديو مخفف" --package-only
```

## 📲 دليل استيراد الاستوديو إلى الآيفون عبر 3uTools

1. **ألبومات التطبيقات (Snapchat, WhatsApp, Instagram):**
   * في 3uTools: ادخل على **Photos** -> **User Album** -> اضغط **New Album** وأنشئ الألبوم بالاسم المناسب.
   * استورد المجلد داخله عبر **Import Folder**.
   * *لترتيب الصور بالآيفون:* ادخل الألبوم بالهاتف -> اضغط `•••` بالأعلى -> اختر **فرز (Sort)** -> **من الأقدم إلى الأحدث**.

2. **الصور الحية (Live Photos):**
   * في 3uTools: ادخل على **Photos** -> **Camera Roll**.
   * اضغط السهم بجانب زر **Import** واختر **Import Live Photo**.
   * حدد مجلد الصور الحية ليتم دمج كل صورة وفيديو كصورة حية تتحرك باللمس.

3. **الصور العامة (Camera Roll):**
   * في 3uTools: ادخل على **Photos** -> **Camera Roll**.
   * اضغط **Import** -> **Import Folder**، وحدد مجلد الصور العامة.
   * ستنزل كافة الصور والفيديوهات مباشرة في مكتبة الآيفون، وسيتولى iOS ترتيبها زمنياً تلقائياً.
